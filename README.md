# 北医物理学实验预习报告 Skill

专用于北京大学医学部（北医）物理学实验的 Codex skill。先读取教材各实验首页旁二维码中的**北医实验内容及要求**，以此为主要依据，再结合教材、课程绪论和当次补充任务，制作可誊抄、能在课上记录真实数据的预习材料。**实操视频无需查看。**

## 教材与二维码资源

仓库附带[《医用物理实验》第3版](beiyi-physics-lab/references/textbooks/医用物理实验_第3版.pdf)，即本任务此前提供的教材；封面书名为《医用物理实验》。各实验首页二维码可能提供北医的实验内容及要求、仪器介绍、参考表格及其他补充资料，也可能同时列出其他院校资源。

准备报告前先读对应实验的北医任务文档；按需阅读补充文字与图片，跳过实操视频。二维码内北医的具体任务范围、采样及操作安排优先于教材一般步骤。链接失效或关键文档不可读时，应说明并补取资料，不能假装已经读过。

教材通过Git LFS保存，普通ZIP下载可能只包含指针文件。获取完整教材和校验信息见[教材说明](beiyi-physics-lab/references/textbooks/README.md)。

## 产出

| 文件 | 用途 | 默认安排 |
| --- | --- | --- |
| **预习报告.pdf** | 课前准备，课上填写数据，课后补全处理与讨论 | 约 6～7 页，包含全部指定任务、必要原理图和空白数据表 |
| **图表打印裁剪稿.pdf** | A4 打印、裁剪后贴入 B5 实验报告纸 | 全部图、表分别保留；约 86% 缩放、裁剪虚线、2 mm 留边 |
| **附录.pdf**（按需） | 独立电子查阅的分度表、参考表或较长计算示例 | 无必要则不制作；不混入默认打印裁剪稿 |

6～7 页、B5 粘贴、误差简写、讨论只留标题等是本 skill 的工作默认值，**不是北医课程的统一规定**。每次实验以当次课程材料和用户的新要求为准。它不把“温度传感器”的采样间隔、终点温度和表格行数套用到其他实验。

## 使用

先按照[教材说明](beiyi-physics-lab/references/textbooks/README.md)取得完整教材，再把仓库中的 `beiyi-physics-lab` 文件夹放入 Codex 的个人 `skills` 目录，然后在新对话中调用：

```text
使用 $beiyi-physics-lab，为我准备下一次北医物理学实验“实验名称”的预习材料。
请先读取对应实验首页二维码中的北医实验内容及要求，以此为主，结合教材和当前绪论，制作预习报告、适配 B5 的图表打印裁剪稿，必要时单独制作附录。实操视频无需查看。
```

请给出实验名称或编号，以及当前课程绪论和当次补充要求；也可直接提供二维码中北医文档的副本。报告和图表保留真实读数填写位置，不能预填示例数据冒充实验结果。

## 可复用的裁剪工具

`beiyi-physics-lab/scripts/build_cutouts.py` 接受已有报告和图表位置清单，保留 PDF 矢量文字与线条，自动排为 A4 裁剪页。它不会自动猜测图表边界；应先根据实际报告制作清单并检查图名、坐标单位及边缘元件是否完整。

```text
python -m pip install -r requirements.txt
python beiyi-physics-lab/scripts/build_cutouts.py report.pdf figures.json cutouts.pdf --layout-json work/layout.json
python -m unittest discover -s tests -v
```

清单格式及字体设置见 [裁剪规范](beiyi-physics-lab/references/cutouts.md)。工具不会联网或上传材料。
